# Quick Deploy (frps / frpc)

This fork includes interactive deployment scripts for fast bootstrap on Unix-like environments (Linux/macOS/FreeBSD/OpenBSD/Termux-like Android shells).

## Entry Script

```bash
wget -O- https://raw.githubusercontent.com/lovitus/frp/dev/hack/quick-deploy/install.sh | bash -
```

Or:

```bash
curl -fsSL https://raw.githubusercontent.com/lovitus/frp/dev/hack/quick-deploy/install.sh | bash -
```

The script asks whether to deploy `frps` or `frpc`.

## Behavior

- Auto-detect OS/arch and download matching binary package.
- Default to the most recent GitHub release (latest published release).
- Strict input validation for required fields and ports (`1..65535`).
- Config files are generated in the current working directory.
- No systemd/service setup is done; process lifecycle is user-managed.

## frps Flow

The script asks for:

- `bindPort`
- `mixBindPort`
- one connection password used to generate:
  - `ss://chacha20-ietf-poly1305:<password>`
  - `kcp://<password>`
  - `ssh://frp:<password>`
- `webServer.addr` (default `0.0.0.0`)
- `webServer.port` (default `mixBindPort + 1`)
- dashboard password (default to the same connection password)

Generated file: `./frps.toml`

Validation:

- `./frps verify -c ./frps.toml`
- short smoke start check (`./frps -c ./frps.toml`, then stop)

After success, the script prints:

- one-click `frps` start command
- one-click `frpc` install command preloaded with `mixBindPort` and `mixToken` (base64-encoded for safer shell transport)

## frpc Flow

Two modes are supported:

1. **Preset mode** (recommended): use the command generated by `install-frps.sh`
   - asks only:
     - `serverAddr`
     - `clientID`
2. **Standalone mode**: run `install-frpc.sh` directly without preset params
   - asks:
     - `mixBindPort`
     - one connection password (builds default `mixToken`)
     - `serverAddr`
     - `clientID`

Generated file: `./frpc.toml`

Defaults included:

- `allowGatewayTunnels = true`
- `mixAllowGateway = true`
- `loginFailExit = false`
- commented fallback host template:
  - `# mixFallbackHosts = "backup-a.example.com,backup-b.example.com:7002"`

Validation:

- `./frpc verify -c ./frpc.toml`
- short smoke start check (non-fatal warning if server is unreachable)

## Direct Script Examples

Deploy server directly:

```bash
wget -O- https://raw.githubusercontent.com/lovitus/frp/dev/hack/quick-deploy/install-frps.sh | bash -
```

Deploy client directly:

```bash
wget -O- https://raw.githubusercontent.com/lovitus/frp/dev/hack/quick-deploy/install-frpc.sh | bash -
```

Use fixed release tag:

```bash
wget -O- https://raw.githubusercontent.com/lovitus/frp/dev/hack/quick-deploy/install-frps.sh | \
  bash -s -- --repo lovitus/frp --release-tag v0.68.1-mix.16
```
